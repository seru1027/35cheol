# 35cheol

동아리/소규모 조직 관리 서비스 (가칭) — 10주 개인 프로젝트.

여러 동아리·소모임이 각자의 구성원, 공지, 일정, 회비를 한 곳에서 관리하고,
사람마다 조직별 역할(회장/운영진/일반 회원)에 맞는 권한만 가지는 웹 서비스.

가장 중요한 목표는 서비스 아이디어가 아니라 **개발 경험**이다.
멀티테넌시, RBAC, 인증, 관계형 데이터 설계를 직접 구현하며 배운다.

## 기술 스택

- Frontend: React (`client/`)
- Backend: Node.js + Express.js (`server/`)
- Database: MySQL

## 구조

```
35cheol/
├── client/   # React 프론트엔드 (2주차부터 작업)
└── server/   # Express 백엔드 (1주차부터 작업)
```

## 학습 방식

별도 공부 기간 없이 개발하면서 그때그때 학습한다. AI는 적극 활용하되
이해·수정·디버깅은 직접 수행한다.
